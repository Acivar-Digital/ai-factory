### Extraction Pattern

Replace:
```python
def get_ge_ju_pattern(key: str) -> GeJuPattern | None:
    match key:
        case 'zheng_guan_ge':
            return GeJuPattern(name='正官格', ...)
        case 'fei_tian_lu_ma':
            return GeJuPattern(name='飞天禄马', ...)
        # ... 23 more cases
        case _:
            return None
```

With:
```python
_GE_JU_DATA: tuple[tuple[str, GeJuPattern], ...] = (
    ('zheng_guan_ge', GeJuPattern(name='正官格', ...)),
    ('fei_tian_lu_ma', GeJuPattern(name='飞天禄马', ...)),
    # ... all 25 cases
)

def get_ge_ju_pattern(key: str) -> GeJuPattern | None:
    for k, pattern in _GE_JU_DATA:
        if k == key:
            return pattern
    return None
```

CC drops from 29 → 2. The function signature, return type, and all callers remain unchanged.
